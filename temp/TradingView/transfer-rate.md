#### What is "Transfer rate"?

The number of successful non-zero asset transfers per second.

A single transaction can initiate multiple transfers, so the number of transfers may exceed the number of transactions.

#### Why is "Transfer rate" important?

This metric reflects the intensity of actual value movement on the network. Unlike Transaction Rate, it focuses specifically on asset movement rather than the number of operations as such. This makes it possible to separately assess asset circulation dynamics and the scale of network economic activity.
