#### What is "Blocks mined"?

The number of blocks created and included in the blockchain’s main chain over the selected period.

#### Why is "Blocks mined" important?

The number of blocks reflects the block production pace over the selected period. A stable value indicates normal consensus operation, while deviations may be associated with changes in difficulty, hash rate, or protocol parameters. The metric helps assess network performance and resilience.

#### How is "Blocks mined" calculated?

The metric is calculated by counting all blocks included in the blockchain’s main chain over the selected period.
