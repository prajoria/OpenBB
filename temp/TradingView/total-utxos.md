#### What is "Total UTXOs"?

The total number of unspent transaction outputs (UTXOs) currently existing on the Bitcoin network.

#### Why are "Total UTXOs" important?

Total UTXOs reflect the size of the current set of unspent outputs stored by nodes for transaction validation. Changes in this indicator affect the amount of data required to run a full node and help evaluate long-term network state dynamics.
