#### What is "Active addresses with contracts"?

The number of unique addresses that were active on the network over the selected period as senders, recipients, or initiators of a smart-contract call. Only successful transactions are included.

#### Why are "Active addresses with contracts" important?

The metric reflects network activity while accounting for smart-contract interactions. Unlike the base active-addresses metric, this indicator helps assess user engagement with the network’s contract infrastructure, including use of decentralized applications. Growth can indicate broader smart-contract usage and increasing complexity of transaction activity.
