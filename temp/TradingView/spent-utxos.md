#### What is "Spent UTXOs"?

The number of transaction outputs that were used as inputs to new transactions over the selected period.

#### Why are "Spent UTXOs" important?

The metric reflects activity in spending existing transaction outputs. Growth in spent UTXOs can indicate higher fund movement volume or consolidation of outputs. Comparing created and spent UTXOs helps assess whether the UTXO set is expanding or contracting, which affects network state structure and storage requirements.

#### How are "Spent UTXOs" calculated?

The metric is calculated by counting all UTXOs used as transaction inputs over the selected period.
