#### What is "Mean transaction size in bytes"?

The average transaction size over the selected period, expressed in bytes.

#### Why is "Mean transaction size in bytes" important?

The metric reflects the average amount of data per transaction. Changes can be associated with changes in transaction structure, such as the number of inputs and outputs. The indicator supports analysis of network usage patterns and transaction-size dynamics.

#### How is "Mean transaction size in bytes" calculated?

Mean transaction size is calculated as the total transaction size in bytes divided by the number of transactions over the selected period.
