#### What is "Mean block size in bytes"?

The average block size in bytes, calculated as the total block size divided by the number of blocks over the selected period.

#### Why is "Mean block size in bytes" important?

Mean block size reflects the degree of block-space utilization. Values close to the maximum allowable block size can indicate high network activity and strong demand for transaction inclusion. The metric helps assess network load and how efficiently available block space is used.
