#### What is "Median UTXO value created"?

The median number of coins in newly created UTXOs over the selected period, expressed in BTC.

#### What is "Median UTXO value created in USD"?

The median number of coins in newly created UTXOs over the selected period, expressed in US dollars.

#### Why are "Median UTXO value created" and "Median UTXO value created in USD" important?

The median reflects the typical size of created UTXOs without being distorted by extremely large or small values. Unlike the mean, the median is less sensitive to outliers and enables a more accurate assessment of characteristic transaction-output sizes.

The USD version additionally allows analysis of the economic significance of created outputs, accounting for market price changes.

#### How are "Median UTXO value created" and "Median UTXO value created in USD" calculated?

The median is determined by ordering all created UTXO values over the period and selecting the central value of the distribution. For the USD version, values are converted to US dollars.
