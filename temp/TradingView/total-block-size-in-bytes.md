#### What is "Total block size in bytes"?

The aggregate size of all blocks created during the selected period, expressed in bytes.

#### Why is "Total block size in bytes" important?

Total block size reflects the volume of data added to the blockchain over the period. An increase can indicate higher network activity and transaction volume, as well as higher storage requirements. The metric helps assess blockchain growth rate and node infrastructure load.

#### How is "Total block size in bytes" calculated?

Total block size is calculated as the sum of the byte sizes of all blocks created during the selected period.
