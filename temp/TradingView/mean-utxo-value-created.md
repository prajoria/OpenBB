#### What is "Mean UTXO value created"?

The average number of coins in newly created UTXOs over the selected period, expressed in BTC.

#### What is "Mean UTXO value created in USD"?

The average number of coins in newly created UTXOs over the selected period, expressed in USD.

#### Why are "Mean UTXO value created" and "Mean UTXO value created in USD" important?

The metric reflects the average size of newly created UTXOs and helps assess the structure of fund distribution on the network. Higher mean values can indicate the formation of larger outputs, while lower values can indicate the creation of smaller UTXOs.

The BTC metric reflects distribution within the network, while the USD version enables comparison of the economic scale of created outputs over time accounting for market price changes.

#### How are "Mean UTXO value created" and "Mean UTXO value created in USD" calculated?

Mean UTXO value created is calculated as total coins in newly created UTXOs divided by the number of created UTXOs over the selected period. For the USD version, values are converted to US dollars.
