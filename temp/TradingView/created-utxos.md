#### What is "Created UTXOs"?

The number of new unspent transaction outputs created on the Bitcoin network over the selected period.

#### Why are "Created UTXOs" important?

The metric reflects the intensity of new transaction-output creation and therefore characterizes the structure of fund distribution on the network. Growth in created UTXOs can indicate higher transaction activity and more granular distribution, while a decline can indicate less active creation of new outputs. The indicator also affects the size of the UTXO set that nodes must store for transaction verification.

#### How are "Created UTXOs" calculated?

The metric is calculated by counting all new transaction outputs created over the selected period.
