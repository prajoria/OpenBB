#### What is "Block height"?

Block height is the total number of blocks ever created and included in the blockchain’s main chain, starting from the genesis block (block 0).

#### Why is "Block height" important?

Block height reflects the network’s current position in its history and allows determining the blockchain’s age relative to the genesis block.

The metric is used to track network progress, synchronize nodes, coordinate protocol upgrades, and reference specific points in blockchain history.
