#### What is "Total UTXO value created"?

The total number of coins in newly created UTXOs over the selected period, expressed in BTC.

#### What is "Total UTXO value created in USD"?

The total number of coins in newly created UTXOs over the selected period, expressed in US dollars.

#### Why are "Total UTXO value created" and "Total UTXO value created in USD" important?

The metric reflects the aggregate amount of funds distributed into new UTXOs over the period. An increase may indicate higher fund movement volume and overall economic activity on the network.

The USD version allows assessment of this amount in a comparable monetary denomination and analysis of dynamics over time.

#### How are "Total UTXO value created" and "Total UTXO value created in USD" calculated?

Total UTXO value created is calculated as the sum of all values of newly created UTXOs over the selected period. For the USD version, values are converted to US dollars and summed.
