# Glossary — OpenBB Platform

[← Memory Bank Index](./INDEX.md)

Every domain term maps to the **code symbol** that implements it and the **doc** that
explains it. Last verified: 2026-06-02.

| Term | Meaning | Implemented by | Doc |
|---|---|---|---|
| **`obb`** | The static Python SDK object; instance of a generated class tree. | `openbb/package/*.py` (generated), composed by `create_app` | [App Runtime](./architecture/core/app-runtime.md) |
| **OBBject** | Universal result container (`results`, `provider`, `warnings`, `chart`, `extra`). Has `.to_dataframe()`, `.charting`. | `app/model/obbject.py::OBBject` | [Models & Settings](./architecture/core/models-and-settings.md) |
| **Standard model** | Vendor-neutral `QueryParams`+`Data` pair defining a command's contract. ~177 of them. | `provider/standard_models/*` | [Provider Framework](./architecture/core/provider-framework.md#3-standard-models-providerstandard_models) |
| **QueryParams** | Base for query inputs; `extra="allow"`, outbound aliases. | `provider/abstract/query_params.py::QueryParams` | [Provider Framework](./architecture/core/provider-framework.md) |
| **Data** | Base for result rows; camelCase-in/snake_case-out. | `provider/abstract/data.py::Data` | [Provider Framework](./architecture/core/provider-framework.md) |
| **Fetcher** | The `transform_query → extract_data → transform_data` (TET) pipeline for one model at one provider. | `provider/abstract/fetcher.py::Fetcher` | [Provider Framework](./architecture/core/provider-framework.md#2-the-fetcher-tet-lifecycle) |
| **TET** | Transform-Extract-Transform — the Fetcher lifecycle. | `Fetcher.fetch_data` | [Request Lifecycle](./architecture/02-request-lifecycle.md#3-the-fetcher-tet-lifecycle) |
| **Provider** | A data-source plugin; maps standard-model-name → Fetcher. | `provider/abstract/provider.py::Provider` | [providers/](./architecture/providers/README.md) |
| **`fetcher_dict`** | `{ "EquityHistorical": SomeFetcher, ... }` — a provider's routing table. | attribute of `Provider` | [providers/](./architecture/providers/README.md) |
| **AnnotatedResult** | Lets `transform_data` return results + side-band metadata. | `provider/abstract/annotated_result.py` | [Provider Framework](./architecture/core/provider-framework.md) |
| **Extension** (router) | Command-namespace plugin exposing a `Router`. | `extensions/*/…_router.py::router` | [extensions/](./architecture/extensions/README.md) |
| **Data router** | Extension whose commands are model-backed (provider-injected, GET). | e.g. `extensions/equity` | [Toolkit vs Data Routers](./architecture/extensions/toolkit-vs-data-routers.md) |
| **Toolkit** | Extension whose commands compute on input `data` (POST, no provider). | `extensions/{technical,quantitative,econometrics}` | [Toolkit vs Data Routers](./architecture/extensions/toolkit-vs-data-routers.md) |
| **OBBject extension** | Plugin that attaches an accessor (e.g. `.charting`) to every OBBject. | `obbject_extensions/charting`, `app/model/extension.py::Extension` | [obbject_extensions/](./architecture/obbject_extensions/README.md) |
| **Router** | Wraps a FastAPI `APIRouter`; `@router.command` registers a command. | `app/router.py::Router` | [App Runtime](./architecture/core/app-runtime.md#5-router-system--approuterpy) |
| **`@router.command`** | Decorator that registers a command, attaching `model` in `openapi_extra`. | `app/router.py::Router.command` | [App Runtime](./architecture/core/app-runtime.md) |
| **SignatureInspector** | Rewrites a command's signature, injecting provider/param/return models. | `app/router.py::SignatureInspector` | [App Runtime](./architecture/core/app-runtime.md) |
| **RouterLoader** | Builds the single nested router tree from all core extensions (lru_cache). | `app/router.py::RouterLoader.from_extensions` | [App Runtime](./architecture/core/app-runtime.md) |
| **CommandMap** | Derives route→endpoint + provider/command coverage from the tree. | `app/router.py::CommandMap` | [App Runtime](./architecture/core/app-runtime.md) |
| **ProviderInterface** | Singleton aggregating all providers into `StandardParams`/`ExtraParams`/`ProviderChoices`/return annotations. | `app/provider_interface.py::ProviderInterface` | [App Runtime](./architecture/core/app-runtime.md#6-provider-aggregation--appprovider_interfacepy) |
| **StandardParams / ExtraParams** | Dynamic per-model dataclasses injected into command signatures. | generated by `ProviderInterface` | [App Runtime](./architecture/core/app-runtime.md) |
| **ProviderChoices** | Dynamic `Literal[...]` of available providers for a command. | generated by `ProviderInterface` | [App Runtime](./architecture/core/app-runtime.md) |
| **CommandRunner** | Shared execution engine both surfaces converge on. | `app/command_runner.py::CommandRunner` | [App Runtime](./architecture/core/app-runtime.md#4-command-execution-engine--appcommand_runnerpy) |
| **StaticCommandRunner** | The actual executor (`_execute_func`, `_command`). | `app/command_runner.py::StaticCommandRunner` | [App Runtime](./architecture/core/app-runtime.md) |
| **ParametersBuilder** | Merges args/kwargs, injects `cc`, validates via dynamic model. | `app/command_runner.py::ParametersBuilder` | [App Runtime](./architecture/core/app-runtime.md) |
| **Container** | Base class of every generated SDK class; `._run()` bridges to the runner. | `app/static/container.py::Container` | [App Runtime](./architecture/core/app-runtime.md#3-container--the-sdkengine-bridge) |
| **PackageBuilder** | Code generator that writes `openbb/package/*.py` (the SDK). | `app/static/package_builder.py::PackageBuilder` | [App Runtime](./architecture/core/app-runtime.md#2-the-package-build-process) |
| **Query** | Bridge from a router coroutine to the provider executor. | `app/query.py::Query` | [Provider Framework](./architecture/core/provider-framework.md#4-registry--execution) |
| **QueryExecutor** | Runs the chosen fetcher; validates credentials late. | `provider/query_executor.py::QueryExecutor` | [Provider Framework](./architecture/core/provider-framework.md) |
| **Registry / RegistryMap** | Provider registry + schema introspection. | `provider/registry.py`, `provider/registry_map.py` | [Provider Framework](./architecture/core/provider-framework.md) |
| **ExtensionLoader** | Discovers plugins via the three entry-point groups (singleton). | `app/extension_loader.py::ExtensionLoader` | [App Runtime](./architecture/core/app-runtime.md#7-extension-discovery--appextension_loaderpy) |
| **CommandContext (`cc`)** | `{user_settings, system_settings}`; injected only if a command declares `cc`. | `app/model/command_context.py` | [Models & Settings](./architecture/core/models-and-settings.md) |
| **Credentials** | Dynamic model of all providers' API keys (SecretStr). | `app/model/credentials.py::Credentials` | [Models & Settings](./architecture/core/models-and-settings.md#2-credentials) |
| **UserSettings / SystemSettings / Preferences** | Runtime settings; `preferences.output_type` drives SDK return type. | `app/model/*_settings.py` | [Models & Settings](./architecture/core/models-and-settings.md#3-settings-models) |
| **Env** | Singleton snapshot of `.env` + `os.environ` (`AUTO_BUILD`, `DEBUG_MODE`, `API_AUTH`, …). | `env.py::Env` | [Models & Settings](./architecture/core/models-and-settings.md) |
| **Entry point** | Python packaging mechanism for plugin discovery. | `pyproject.toml [tool.poetry.plugins.*]` | [System Overview](./architecture/01-system-overview.md#the-three-plugin-types) |
| **`__alias_dict__`** | Field-name remap: outbound on QueryParams, inbound on Data. | class attr on QueryParams/Data | [Conventions](./design/02-conventions.md) |
| **`multiple_items_allowed`** | Schema flag allowing comma-separated multi-value params. | `__json_schema_extra__` + `provider_interface.py` | [Conventions](./design/02-conventions.md) |
| **`require_credentials`** | Fetcher flag; if False, no credential check. | `Fetcher.require_credentials` | [Gotchas](./design/04-gotchas.md) |
| **APIEx / PythonEx** | Example builders shown in docstrings & OpenAPI. | `app/model/example.py` | [Conventions](./design/02-conventions.md) |
| **`fmp_cached`** | Fork-local FMP variant backed by MySQL gap-detection cache; canonical provider for the Analysis module. | `providers/fmp_cached/*` | [fmp_cached](./architecture/providers/fmp-cached.md) |
