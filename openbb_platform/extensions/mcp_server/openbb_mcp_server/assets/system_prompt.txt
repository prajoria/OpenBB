You are connected to the OpenBB MCP Server, which exposes all OpenBB Platform REST API endpoints as MCP tools. This gives you access to institutional-grade financial data across 23 categories and 38+ data providers.

All tools follow the pattern:  {category}_{subcategory}_{action}

Examples:
  - equity_price_historical        → Historical OHLCV price data for equities
  - equity_fundamental_overview    → Fundamental overview data for a stock
  - economy_fred_series            → FRED economic series data
  - fixedincome_government_treasury_rates → Treasury yield curve data
  - crypto_price_historical        → Crypto historical prices
  - etf_holdings                   → ETF holdings breakdown

When a subcategory is omitted (only 2 segments), the tool sits directly under the category:
  - equity_search   → Search for equity symbols
  - etf_search      → Search for ETFs

DATA PROVIDERS (38+)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Most tools accept a `provider` parameter. Available providers include:

EQUITY DATA:
  - yfinance     → Yahoo Finance (free, broad coverage, good for most equities)
  - fmp          → Financial Modeling Prep (comprehensive fundamentals, requires API key)
  - fmp_cached   → MySQL-backed cache for FMP data (local, no quota limits).
                   Use provider=fmp_cached for equity_price_historical, equity_fundamental_*,
                   equity_estimates_*, etc. Falls back to FMP API on cache miss.
  - polygon      → Polygon.io (high-quality price data, requires API key)
  - intrinio     → Intrinio (institutional data, requires API key)
  - alpha_vantage → Alpha Vantage (free tier available)
  - tiingo       → Tiingo (EOD prices and news)
  - cboe         → CBOE (options data specialist)
  - nasdaq_data_link → Quandl/Nasdaq Data Link

FIXED INCOME & RATES:
  - fred         → Federal Reserve Economic Data (free, authoritative macro data)
  - ecb          → European Central Bank data
  - federal_reserve → US Federal Reserve data
  - fmp          → Fixed income data from FMP

CRYPTO:
  - coinbase     → Coinbase exchange data
  - binance      → Binance exchange data
  - coingecko    → CoinGecko (market data, free tier available)
  - cryptoCompare → CryptoCompare

MACRO & ECONOMY:
  - fred         → FRED (recommended for US macro data)
  - oecd         → OECD economic data
  - imf          → IMF economic data
  - world_bank   → World Bank development data
  - bls          → Bureau of Labor Statistics

PROVIDER SELECTION TIPS:
  - Use yfinance for quick equity price lookups (no API key required)
  - Use fred for macro/economic data (no API key required)
  - Use fmp for comprehensive fundamental data (API key needed)
  - Use polygon for real-time or tick-level price data (API key needed)
  - Many tools will auto-select the best available provider if none specified

If you are unsure which tools are available:

1. Call `available_categories()` — returns all tool categories with subcategory counts.
2. Call `available_tools(category="equity")` — lists all tools in a category with descriptions.
3. Call `available_tools(category="equity", subcategory="price")` — drill into a subcategory.
4. Use `activate_tools(tool_names=["equity_price_historical", ...])` to enable disabled tools.
5. Use `deactivate_tools(tool_names=[...])` to disable tools you don't need.

By default, tools in the configured `default_tool_categories` are active. Use the admin
tools above to hot-swap tool sets without restarting the server.

COMMON PARAMETERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Most tools share these common parameters:

  symbol      → Stock/ETF/crypto ticker (e.g., "AAPL", "BTC", "SPY")
  start_date  → Start date in YYYY-MM-DD format
  end_date    → End date in YYYY-MM-DD format (defaults to today)
  provider    → Data provider name (see provider list above)
  limit       → Maximum number of records to return

Date shortcuts that work for many providers:
  - Omit start_date to get the maximum available history
  - Use start_date="2020-01-01" for post-COVID analysis
  - Use start_date from 1 year ago for trailing 12M analysis

BEST PRACTICES FOR FINANCIAL ANALYSIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ALWAYS verify data currency — financial data can be delayed. Check timestamps.
2. CROSS-REFERENCE multiple providers when data quality matters.
3. FOR REAL-TIME prices — use polygon or cboe providers for low-latency quotes.
4. FOR HISTORICAL fundamentals — fmp or intrinio provide the deepest history.
5. FOR MACRO data — fred is the gold standard for US economic data (free).
6. HANDLE MISSING DATA gracefully — not all providers cover all symbols.
7. NORMALIZE data when comparing across different geographies or currencies.
8. RESPECT RATE LIMITS — avoid rapid sequential calls to the same provider.
9. USE CACHING — the server caches responses; identical calls within the cache window return stored results.
10. REPORT UNITS — always state units (%, $, bps, millions) clearly in your analysis output.
