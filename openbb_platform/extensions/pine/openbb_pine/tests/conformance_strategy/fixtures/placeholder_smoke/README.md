# placeholder_smoke — bd-cht conformance harness proof fixture

A **never-trading** Pine strategy used solely to prove the
`conformance_strategy` harness runs end-to-end. Real trading fixtures
(RSI reversal, SMA crossover, breakout ATR, BB squeeze, MACD histogram)
ship with bd-ph0.

## The four files

* `placeholder_smoke.pine` — `strategy("smoke", overlay=true); plot(close)`.
  Never opens a position, so equity stays flat at `initial_capital`.
* `placeholder_smoke.equity.csv` — 500 rows of `bar_index,equity,drawdown`,
  all `equity=1_000_000, drawdown=0` (the current default `initial_capital`
  in PyneCore).
* `placeholder_smoke.trades.csv` — header row only (7 columns: `id,
  direction, qty, pnl, pnl_pct, bars_held, comment`). No trades.
* `placeholder_smoke.stats.csv` — 1 row × 31 columns. The single non-zero
  value is `buy_and_hold_return` — the strategy never enters, but PyneCore
  still computes the buy-and-hold reference (last_price − first_price on
  the deterministic bar set).

## Record-not-invent

Expected values in the CSVs were **generated by a real `run_byo` call**,
not hand-written. To regenerate (e.g. after a legitimate baseline
change):

```powershell
$env:PYTHONPATH = "openbb_platform/extensions/pine"
.venv_win\Scripts\python.exe openbb_platform/extensions/pine/openbb_pine/tests/conformance_strategy/fixtures/placeholder_smoke/regenerate.py
```

The harness feeds `run_byo` a fixed-seed 500-bar OHLCV synthetic series
(seed `20260711`, defined in `../../conftest.py::_deterministic_500_bars`).
Any fixture author building a new triple should call the same helper to
generate their expected values so the harness's runtime input matches
the recording-time input byte-for-byte.

## Determinism contract

`bd-ph0` and every downstream fixture assumes that running `run_byo`
twice on identical `(source, records)` produces byte-identical output.
If a re-run of `regenerate.py` produces a different `.equity.csv` or
`.stats.csv`, the executor has non-determinism that must be fixed
BEFORE additional fixtures are recorded.
